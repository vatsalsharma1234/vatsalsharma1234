### 🚀 Featured Work

**🩺 Multimodal Skin Disease Classifier**  [`disease-classifier`](https://github.com/vatsalsharma1234/disease-classifier/tree/main)
- **Problem:** Classify skin conditions across 21 disease categories using both image and patient-reported symptom data.
- **Approach:** Built an ensemble pipeline combining a ResNet-50 image model with a BERT-based text model, merging predictions with configurable probability weights.
- **Result:** Benchmarked with precision, recall, F1-score, Cohen's kappa, and confusion matrices to validate performance across classes.
- **Stack:** Python, PyTorch, Scikit-learn, Pandas, NumPy, CountVectorizer

**📄 Resume–JD Matching & ATS Scoring Engine**  [`resume-analysis`](https://github.com/vatsalsharma1234/resume-analysis) · *Obcidian Group*
- **Problem:** Give candidates an automated, explainable score of how well their resume matches a job description.
- **Approach:** Extracted resume content from PDF/DOCX and scored similarity using TF-IDF, cosine similarity, and Sentence Transformers.
- **Result:** Surfaces matched vs. missing skills and a similarity score to guide resume improvements.
- **Stack:** FastAPI, Python, Scikit-learn, Sentence Transformers

**📈 Compound Ledger — Historical Investment Backtester**  [`compound-ledger-backtester`](https://github.com/vatsalsharma1234/compound-ledger-backtester)
- Interactive tool that backtests portfolio growth using real historical annual returns across stocks, indices, crypto, and gold — with CAGR, gain/loss, benchmark comparison, and a year-by-year ledger.
- **Stack:** HTML, CSS, JavaScript, SVG

**🎥 Real-Time Face Recognition Attendance System**  [`face-attendance-system`](https://github.com/vatsalsharma1234/face-attendance-system/tree/main) · *Vault of Code*
- End-to-end pipeline for face dataset creation, LBPH model training, confidence-based recognition, and duplicate-free attendance logging, with a Streamlit dashboard for monitoring and filtering records.
- **Stack:** Python, OpenCV (Haar Cascade + LBPH), Streamlit
